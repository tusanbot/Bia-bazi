# پنل مدیریت بیا بازی

آدرس پنل مستقل از Telegram است: /admin/

احراز هویت پنل با نام کاربری/رمز عبور و Cookie امضاشده با HMAC انجام می‌شود. هیچ Telegram initData یا Telegram login برای پنل لازم نیست.

## Secrets

روی Worker این Secretها را تنظیم کنید:

- ADMIN_USERNAME — نام کاربری مدیر
- ADMIN_PASSWORD — رمز عبور مدیر
- ADMIN_SESSION_SECRET — یک مقدار تصادفی طولانی برای امضای session
- ADMIN_INTERNAL_TOKEN — توکن ارتباط امن Worker با Durable Object

اگر ADMIN_INTERNAL_TOKEN تنظیم نشود، کد به‌صورت fallback از ADMIN_SESSION_SECRET استفاده می‌کند؛ بهتر است هر دو جدا باشند.

## قابلیت‌ها

- داشبورد کاربران، کاربران فعال، اتاق‌های فعال، بازی‌های انجام‌شده و گروه‌ها
- فهرست و جستجوی اتاق‌های فعال بر اساس شناسه اتاق، بازی و میزبان
- لغو، بستن و حذف اتاق
- فهرست کاربران و ارسال پیام مستقیم به کاربران شناخته‌شده
- فهرست گروه‌ها با Chat ID، عنوان، تعداد اعضا، اعضای فعال مشاهده‌شده، بازی‌های انجام‌شده و اتاق‌های فعال
- مسدود/رفع مسدودی گروه برای استفاده از ربات
- تازه‌سازی اطلاعات گروه
- خروج ربات از گروه
- ارسال پیام به گروه
- آمار بازی‌ها

## محدودیت Telegram

Bot API تعداد کل اعضای گروه را با getChatMemberCount ارائه می‌کند، اما فهرست کامل اعضای گروه را در اختیار Bot API قرار نمی‌دهد. بنابراین «اعضای فعال» در پنل بر اساس کاربرانی محاسبه می‌شود که در webhookهای قابل مشاهده ربات ثبت شده‌اند، نه کل اعضای آنلاین گروه.

برای دریافت رویداد اضافه/حذف شدن خود ربات، webhook با my_chat_member نیز ثبت می‌شود.
## D1 Migration

Migrationها اکنون به‌صورت رسمی توسط Wrangler از مسیر `workers/game-room/migrations` مدیریت می‌شوند و binding `DB` همین مسیر را در `wrangler.toml` دارد.

برای بررسی وضعیت:

    npm run migrate:list

برای اجرای Migrationهای باقی‌مانده روی D1 اصلی:

    npm run migrate:remote

Migrationهای جدید دیگر نباید از SQLهای قدیمی `database/migrations` یا با کپی‌کردن مستقیم `ALTER TABLE ... ADD COLUMN` اجرا شوند. Worker نیز برای دیتابیس‌های قدیمی، ستون‌های ضروری اتاق و جدول‌های گروه را به‌صورت امن بررسی و در صورت نبودن ایجاد می‌کند.
