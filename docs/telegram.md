# Telegram setup

1. در BotFather ربات ساخته شود.
2. Inline Mode فعال شود.
3. Username ربات در env قرار گیرد.
4. Mini App URL تنظیم شود.
5. Webhook روی Worker ثبت شود.
6. در Mini App، `Telegram.WebApp.initData` به Backend ارسال و در Backend اعتبارسنجی شود.

برای بازی‌های این پروژه از Telegram Mini App استفاده می‌شود؛ Telegram Games API برای هسته بازی لازم نیست.
