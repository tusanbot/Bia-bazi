# Game Room

هسته عمومی اتاق بازی «بیا بازی».

Room فقط مسئول چرخه عمر و بازیکنان است و منطق خود بازی را نمی‌داند.

## قوانین

- ظرفیت Room ثابت است و هنگام ساخت انتخاب می‌شود.
- بعد از رسیدن تعداد بازیکنان به ظرفیت، Room آماده شروع است.
- بعد از شروع، Join و Leave عادی مسدود می‌شوند.
- صندلی‌ها از ۰ شروع می‌شوند و هنگام Leave در حالت waiting دوباره مرتب می‌شوند.
- بازی‌ها باید config مخصوص خودشان را بسازند.

این طراحی اجازه می‌دهد بازی‌های بعدی بدون تغییر Room اضافه شوند.
